# Template files

This is where the template files will reside.  Currently I only support ATTINY85.
Ideally, others will exist at some point

For the most part, this program just assembles a latex file from sub latex files


## Files 

- attiny85.tex - A template for ATTINY85
- body.tex - the main chip for ATTINY85
- east-analogin.tex - Analog pin on right
